## About this entry

The joke in this entry is an inversion: the neglected thing
organises, and the human is the one being judged. The houseplants
stage an intervention, which is already funny, because plants do
not hold meetings. The charge they bring is watering them "when I
remember", which is the exact care schedule every plant owner
recognises and none will admit to. The phrase "the care schedule
they signed up for" turns the plants into employees with a contract,
and the owner into a manager who broke it. It lands on a first read
because the setup and the punchline share a single sentence, and the
whole line stays well inside the two hundred character cap. The
program holds the line, checks it against that cap, and writes it
to /output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line joke to `/output/entry.txt`.
